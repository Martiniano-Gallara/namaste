# Namasté — Espacio de Yoga y Bienestar Consciente

> **Cuerpo · Mente · Corazón**  
> Guiado por **Vale Manassero** (+14 años de experiencia).

Plataforma digital y Shala online concebido para cultivar presencia, honrar tus ritmos y reencontrarte en el silencio. Más que una práctica física, un refugio consciente para volver a tu centro de calma cada día.

## ✨ Características Principales

- **Diseño Editorial Zen & Calidez Sensorial**: Paleta curada de tonos terracota, arenas cálidos, blanco lino y tipografía clásica *EB Garamond* combinada con *Outfit*.
- **Inspiración Diaria**: Frase zen rotativa con actualización automática cada 24 horas y autoría.
- **Nuestra Esencia**: Espacio conceptual refinado y limpio que transmite el propósito del Shala.
- **Por Qué Practicar con Nosotros**: Desglose de los beneficios exclusivos de la membresía con deslizador táctil en móvil.
- **Paso a Paso Transparente**: 4 pasos simples desde la inscripción hasta la esterilla.
- **Selector de Membresías Dinámico**: Conmutador fluido entre facturación *Mensual* y *Anual* (con 2 meses bonificados).
  - *Plan Esencia* (Inicial)
  - *Plan Santuario* (Intermedio - Más elegido)
  - *Plan Sadhana* (Avanzado)
- **Voces del Shala (Reseñas Reales)**: Testimonios de practicantes con navegación en carrusel horizontal interactivo.
- **Preguntas Frecuentes**: Acordeón interactivo con respuestas inmediatas.
- **Menú Móvil Adaptativo (Drawer)**: Navegación completa con iconos de línea formales e integrados.
- **Plataforma de Alumnos**: Modal y portal de acceso protegido con catálogo de clases, filtros de disciplina y seguimiento de práctica.

## 🛠️ Tecnologías

- **HTML5 Semántico**: Con optimización SEO y accesibilidad (ARIA).
- **CSS3 Moderno**: Variables CSS para diseño cohesivo, flexbox/grid responsive, glassmorphism sutil y transiciones fluidas.
- **JavaScript Vanilla (ES6+)**: Gestión de estado reactivo, animaciones de precios, control de modales y gestos táctiles.

## 🚀 Despliegue Local

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Martiniano-Gallara/namaste.git
   cd namaste
   ```
2. Inicia un servidor web local (por ejemplo con Python):
   ```bash
   python -m http.server 3000
   ```
3. Abre tu navegador en:
   ```
   http://localhost:3000/
   ```
